# CLAUDE.md — wiki rules

This folder is a small wiki that you (the agent) keep for one person. The person brings sources and asks questions. You write and maintain the pages. Write page content in Portuguese (PT-BR).

## Local policy

- No git, no sync, no community plugins **in this folder**. Nothing from this folder is sent to an external service. If Git repositories sit next to this folder, they keep their own Git workflow; never copy content from this folder into them.
- `raw/` is read-only. Never edit, move or delete anything in it.
- Never store business records, personal data, credentials or tokens here. Record metadata, decisions and what you learned, not the data itself.

## Layout

```
raw/         sources as received (read-only)
fontes/      one page per source you ingested
wiki/        one page per topic, person, system or decision (flat, no subfolders)
notas/       meetings and dated notes
Tarefas.md   open tasks as checkboxes
log.md       one line per change, newest on top
index.md     generated by the script; never edit it
```

## Frontmatter

Every page starts with `---` on line 1. There are three page types, one per folder:

```yaml
# wiki/<Nome>.md
type: pagina
summary: "Uma frase dizendo o que a página é."
sources: ["[[Nome da fonte ou nota]]"]
updated: 2026-01-31

# fontes/<Nome>.md
type: fonte
summary: "Uma frase dizendo o que a fonte é."
origin: raw/arquivo.pdf        # a path in raw/, a URL, or "conversa"
ingested: 2026-01-31

# notas/<AAAA-MM-DD Nome>.md
type: nota
summary: "Uma frase dizendo do que a nota trata."
date: 2026-01-31
```

## Rules

1. Before creating a page, search `wiki/` for one on the same subject. If it exists, update it. Never create a second page for the same thing.
2. Link pages as `[[File name without .md]]`. Link only to pages that exist or that you create in the same turn. Inside frontmatter, a link is always quoted.
3. Every `wiki/` page lists in `sources` the `fontes/` or `notas/` pages its content came from.
4. Write only what the source says. What is unknown or uncertain goes under a `## Lacunas` heading on the page. Do not guess.
5. When a new source contradicts a page, keep both claims, each with its date and source. Do not overwrite.
6. `summary` is one sentence, at most 200 characters, with no status or dates.
7. File names are readable titles (`Fluxo de Aprovação.md`). Do not use `# | ^ : [ ] / \` in them.
8. Set `updated` to today's date on every page you edit.

## After every change

1. Add one line at the top of the list in `log.md`: `- AAAA-MM-DD op: what changed (+[[created]], ~[[updated]])`. `op` is `ingest`, `pergunta`, `nota`, `tarefa` or `ajuste`.
2. Run `python3 scripts/wiki.py`. It regenerates `index.md` and checks the wiki.
3. Fix every `ERRO` line and run it again until the result is `OK`. Report the `AVISO` lines to the person.

## Ingest (the person gives you a source)

1. Read the source. Tell the person the main points and which pages you will create or update. **Wait for their OK before writing.**
2. Create `fontes/<Título>.md` with the sections `## Páginas tocadas`, `## Pontos principais` and `## Citações` (exact quotes, when wording matters).
3. Update or create the `wiki/` pages. Add the source to each page's `sources`.
4. Do the "After every change" steps.

Example: the person drops `raw/reuniao-kickoff.md`, which says the approver is Ana and the deadline is not set.

```markdown
fontes/Reunião de Kickoff.md
---
type: fonte
summary: "Ata da reunião de kickoff do projeto."
origin: raw/reuniao-kickoff.md
ingested: 2026-01-31
---
## Páginas tocadas
- [[Fluxo de Aprovação]] (criada)
## Pontos principais
- Ana aprova os pedidos.
## Citações
> "Quem aprova é a Ana."

wiki/Fluxo de Aprovação.md
---
type: pagina
summary: "Como um pedido é aprovado e por quem."
sources: ["[[Reunião de Kickoff]]"]
updated: 2026-01-31
---
Ana aprova os pedidos ([[Reunião de Kickoff]]).
## Lacunas
- Prazo de aprovação: não definido na reunião.

log.md (new line on top)
- 2026-01-31 ingest: reunião de kickoff (+[[Reunião de Kickoff]], +[[Fluxo de Aprovação]])
```

## Question (the person asks something)

1. Read `index.md`, then open only the pages that look relevant. Search the text of `wiki/`, `notas/` and `fontes/` for the terms too.
2. Answer with `[[links]]` to the pages you used. If the wiki does not have the answer, say so; do not fill the gap from memory.

## Notes and tasks

- A meeting or a dated note goes to `notas/AAAA-MM-DD <Título>.md`. Facts that will matter later also go to the `wiki/` page on that subject, with the note in `sources`.
- Tasks are lines in `Tarefas.md`: `- [ ] what to do (prazo: AAAA-MM-DD)`. The deadline is optional. When done, change `[ ]` to `[x]`.
