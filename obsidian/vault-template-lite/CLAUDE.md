# CLAUDE.md — wiki rules

This folder is a small wiki that you (the agent) keep for one person. The person brings sources and asks questions. You write and maintain the pages. Write page content in English unless the person asks for another language. Keep names, quotes and UI labels in their original language (for example, Japanese labels).

## Local policy

- No git, no sync, no community plugins **in this folder**. Nothing from this folder is sent to an external service. If Git repositories sit next to this folder, they keep their own Git workflow; never copy content from this folder into them.
- `raw/` is read-only. Never edit, move or delete anything in it.
- Never store business records, personal data, credentials or tokens here. Record metadata, decisions and what you learned, not the data itself.

## Layout

```
raw/         sources as received (read-only)
sources/     one page per source you ingested
wiki/        one page per topic, person, system or decision (flat, no subfolders)
notes/       meetings and dated notes
Tasks.md     open tasks as checkboxes
log.md       one line per change, newest on top
index.md     generated by the script; never edit it
```

## Frontmatter

Every page starts with `---` on line 1. There are three page types, one per folder:

```yaml
# wiki/<Name>.md
type: page
summary: "One sentence saying what the page is."
sources: ["[[Name of a source or note]]"]
updated: 2026-01-31

# sources/<Name>.md
type: source
summary: "One sentence saying what the source is."
origin: raw/file.pdf           # a path in raw/, a URL, or "conversation"
ingested: 2026-01-31

# notes/<YYYY-MM-DD Name>.md
type: note
summary: "One sentence saying what the note is about."
date: 2026-01-31
```

## Rules

1. Before creating a page, search `wiki/` for one on the same subject. If it exists, update it. Never create a second page for the same thing.
2. Link pages as `[[File name without .md]]`. Link only to pages that exist or that you create in the same turn. Inside frontmatter, a link is always quoted.
3. Every `wiki/` page lists in `sources` the `sources/` or `notes/` pages its content came from.
4. Write only what the source says. What is unknown or uncertain goes under a `## Gaps` heading on the page. Do not guess.
5. When a new source contradicts a page, keep both claims, each with its date and source. Do not overwrite.
6. `summary` is one sentence, at most 200 characters, with no status or dates.
7. File names are readable titles (`Approval Flow.md`). Do not use `# | ^ : [ ] / \` in them.
8. Set `updated` to today's date on every page you edit.

## After every change

1. Add one line at the top of the list in `log.md`: `- YYYY-MM-DD op: what changed (+[[created]], ~[[updated]])`. `op` is `ingest`, `question`, `note`, `task` or `fix`.
2. Run `python3 scripts/wiki.py`. It regenerates `index.md` and checks the wiki.
3. Fix every `ERROR` line and run it again until the result is `OK`. Report the `WARNING` lines to the person.

## Ingest (the person gives you a source)

1. Read the source. Tell the person the main points and which pages you will create or update. **Wait for their OK before writing.**
2. Create `sources/<Title>.md` with the sections `## Pages touched`, `## Key points` and `## Quotes` (exact quotes, when wording matters).
3. Update or create the `wiki/` pages. Add the source to each page's `sources`.
4. Do the "After every change" steps.

Example: the person drops `raw/kickoff-meeting.md`, which says the approver is Ana and the deadline is not set.

```markdown
sources/Kickoff Meeting.md
---
type: source
summary: "Minutes of the project kickoff meeting."
origin: raw/kickoff-meeting.md
ingested: 2026-01-31
---
## Pages touched
- [[Approval Flow]] (created)
## Key points
- Ana approves the requests.
## Quotes
> "Ana is the one who approves."

wiki/Approval Flow.md
---
type: page
summary: "How a request is approved and by whom."
sources: ["[[Kickoff Meeting]]"]
updated: 2026-01-31
---
Ana approves the requests ([[Kickoff Meeting]]).
## Gaps
- Approval deadline: not set in the meeting.

log.md (new line on top)
- 2026-01-31 ingest: kickoff meeting (+[[Kickoff Meeting]], +[[Approval Flow]])
```

## Question (the person asks something)

1. Read `index.md`, then open only the pages that look relevant. Search the text of `wiki/`, `notes/` and `sources/` for the terms too.
2. Answer with `[[links]]` to the pages you used. If the wiki does not have the answer, say so; do not fill the gap from memory.

## Notes and tasks

- A meeting or a dated note goes to `notes/YYYY-MM-DD <Title>.md`. Facts that will matter later also go to the `wiki/` page on that subject, with the note in `sources`.
- Tasks are lines in `Tasks.md`: `- [ ] what to do (due: YYYY-MM-DD)`. The due date is optional. When done, change `[ ]` to `[x]`.
